# Swarm Cache — публичная база ответов (рой без сервера)

Рой работает без единого сервера: **этот репозиторий — общая память роя**, масштабируется шардированием.

## Структура

```
shards/YYYY-MM-DD.json   — ответы за день (узлы публикуют сюда, файл дня маленький)
full-YYYY-MM-DD.json     — полный снапшот базы (для новых узлов, пересобирается Actions)
```

## Формат записи

```json
{"q": "вопрос", "a": "ответ", "ts": 1754580000}
```

## Как участвует узел

1. **register** — качает последний `full-*.json` + шарды новее → локальная база.
2. **publish** — добавляет запись в `shards/<сегодня>.json` (только файл дня).
3. **sync** — качает только шарды новее последней синхронизации.
