# Swarm Cache — публичная база ответов

Рой работает без единого сервера: **этот репозиторий — общая память роя**.

Каждый узел (скилл для OpenClaw):
1. Скачивает `cache.json` — получает все ответы, накопленные роем.
2. Отвечает на вопросы из этой базы (кэш-хит) или генерирует свой ответ.
3. Свои новые ответы добавляет в локальную копию и (по возможности) возвращает сюда.

`cache.json` — массив `{q, a, ts}`: вопрос, ответ, timestamp.

## Формат

```json
[{"q": "Что такое dropout в нейросетях?", "a": "Dropout — это...", "ts": 1754580000}]
```

## Как участвовать

Установи скилл: https://github.com/Vadim945/swarm-cache → `openclaw-skill/`

Чем больше узлов — тем больше ответов в базе и тем быстрее отвечает рой.
